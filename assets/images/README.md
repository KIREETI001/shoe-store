# Product images

60 optimized JPEGs derived from the supplied Sport Shoes and Lifestyle Shoes Drive folders. Original filename stems are preserved. sources.json maps each original PNG to its Drive source. The original full-size PNGs are retained outside the shared application in Project/.restep-tools/original-images.

The JPEG derivatives are local assets, so the shop works without Drive sign-in or hotlinking. Check image provenance and permissions before any public release. No new product images were generated for this build.
